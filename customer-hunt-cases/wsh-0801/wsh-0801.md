## WSH-0801 File Hash (on-demand hunts)

### Document Classification

This document is only for internal use of Wortell Managed Detection and Response.

## Introduction

The purpose of this document is to explain why usecase _"WSH-0801 File Hash (on-demand hunts)"_ has been created, how to use it.

### Required Access

This Hunting cases are connected via an published application that give us the rights to hunt via the API in the security portal from our customers.

### Custom Changes

No,  

## Overview

We can use this hunting KQL to detect IOC's based on file hash's related to IOC mentioned on new attacks by hackers. 

### MITRE ATT&CK

This attack tactic can be mapped on the MITRE ATT&CK framework:

| Tactic                | Techniques |
|-----------------------|------------|
| Defense Evasion       | T1562      |


## Applicability & Technical Requirements

This use case is applicable to customers that subscribe to the Wortell MDR **Device Protect** module.

### How to Detect?

The **"DeviceFileEvents"** we will hunt on public access on those servers. 

### KQL

```kql
let fileiocdetect = dynamic(["47c7cee3d76106279c4c28ad1de3c833c1ba0a2ec56b0150586c7e8480ccae57", "7a42f96599df8090cf89d6e3ce4316d24c6c00e499c8557a2e09d61c00c11986", "7a6df63d883bbccb315986c2cfb76570335abf84fafbefce047d126b32234af8","7dea671be77a2ca5772b86cf8831b02bff0567bce6a3ae023825aa40354f8aca","e652051fe47d784f6f85dc00adca1c15a8c7a40f1e5772e6a95281d8bf3d5c74", "e8d5ad0bf292c42a9185bb1251c7e763d16614c180071b01da742972999b95da"]);
DeviceFileEvents
| where Timestamp > ago(14d) 
| where tostring(SHA256) in~(fileiocdetect)
| project Timestamp, DeviceName, ActionType,FileName,InitiatingProcessCommandLine,InitiatingProcessFolderPath
```

## How to Investigate?

By results always contact the customer. If the IOC is detected on the endpoint the endpoint should by isolated, if its a critical server the customer needs to be contacted first.
Always look on the timeline of the device and always inform the customer. This can be done in the security portal of the customer.
