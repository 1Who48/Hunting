## WSH-0804 CVE Hunt (on-demand hunts)

### Document Classification

This document is only for internal use of Wortell Managed Detection and Response.

## Introduction

The purpose of this document is to explain why usecase _"WSH-0804 CVE Hunt (on-demand hunts)"_ has been created, how to use it.

### Required Access

This Hunting cases are connected via an published application that give us the rights to hunt via the API in the security portal from our customers.

### Custom Changes

No

## Overview

When new CVE's are published and we need to hunt related to those CVE's we will use this KQL to detect the device included the user that is working on the device.

## Applicability & Technical Requirements

This use case is applicable to customers that subscribe to the Wortell MDR **Device Protect** module.

### How to Detect?

The **"DeviceTvmSoftwareInventory"** we will hunt on public access on those servers.

### KQL

```kql
    DeviceTvmSoftwareVulnerabilities
        | where CveId == "CVE-2024-5655"
        | join kind=leftouter (DeviceInfo
        | where Timestamp > ago(10d)
        ) on DeviceId
        | distinct DeviceName, CveId, SoftwareVersion, OSVersion, DeviceId, tostring(LoggedOnUsers)
```
