## WSH-0805 FileName Detection (on-demand hunts)

### Document Classification

This document is only for internal use of Wortell Managed Detection and Response.

## Introduction

The purpose of this document is to explain why usecase _"WSH-0805 FileName Detection (on-demand hunts)"_ has been created, how to use it.

### Required Access

This Hunting cases are connected via an published application that give us the rights to hunt via the API in the security portal from our customers.

### Custom Changes

No

## Overview

When attackers using a attack based on a file name we can hunt for that file in the customer environment to see devices are compromised. 

### MITRE ATT&CK

This attack tactic can be mapped on the MITRE ATT&CK framework:

| Tactic                | Techniques |
|-----------------------|------------|
| Privilege Escalation  | TA0004     |


## Applicability & Technical Requirements

This use case is applicable to customers that subscribe to the Wortell MDR **Device Protect** module.

### How to Detect?

The **"EmailAttachmentInfo"** we will hunt on public access on those servers.

### KQL

```kql
    EmailAttachmentInfo
    | where Timestamp > ago(7d)
    | join DeviceFileEvents on FileName
    | where FileName contains "FileMalwareDetected"
    | where FileName1 has "instrucciones.txt"
```

## How to Investigate?

When those files are detected, the device needs to be isolated. If its a critical server than the customer needs to be informed directly by the phone and e-mail.
