## WSH-0803 Software hunt (on-demand hunts)

### Document Classification

This document is only for internal use of Wortell Managed Detection and Response.

## Introduction

The purpose of this document is to explain why usecase _"WSH-0803 Software hunt (on-demand hunts)"_ has been created, how to use it.

### Required Access

This Hunting cases are connected via an published application that give us the rights to hunt via the API in the security portal from our customers.

### Custom Changes

No

## Overview

When a application is exploitable and there is no CVE in time, we will use this KQL to detect the software on the endpoints. When the software is detected the customer needs to be informed. 

Most cases this case us used for small applications or non standard applications on our portfolio.

### MITRE ATT&CK

This attack tactic can be mapped on the MITRE ATT&CK framework:

| Tactic                | Techniques |
|-----------------------|------------|
| Defense Evasion       | T1562      |


## Applicability & Technical Requirements

This use case is applicable to customers that subscribe to the Wortell MDR **Device Protect** module.

### How to Detect?

The **"DeviceTvmSoftwareInventory"** we will hunt on public access on those servers.

### KQL

```kql
    DeviceTvmSoftwareInventory
    | where SoftwareVendor has "Qliksens" or SoftwareName has "Qliksens" or SoftwareVendor has "Qlik sens" or SoftwareName has "Qlik sens"
```

## How to Investigate?

When the software is detected, the customer must be informed.
