## WSH-0806 Identify network shares with write permissions set to Everyone on highly exposed devices

## Document Classification

This document is only for internal use of Wortell Managed Detection and Response.

## Introduction

The purpose of this document is to explain why usecase _"WSH-0806 Identify network shares with write permissions set to Everyone on highly exposed devices"_ has been created, how to use it. (every month this will be running to see if new shares on critical devices are present)

### Required Access

These hunting cases are linked through a published application that grants us permission to perform threat hunting via the API in our customers' security portals.

### Custom Changes

* No custom changes are made.

## Overview

Informational for our customer, share with write access for everyone included high exposed device.

## Applicability & Technical Requirements

This use case is applicable to customers that subscribe to the Wortell MDR **Device Protect** module.

### How to Detect?

The **"DeviceTvmSecureConfigurationAssessment "** we can hunt on modification on the Reg file that enable RDP.

### KQL

```kql
    let DevVulNetShares = DeviceTvmSecureConfigurationAssessment 
        | where ConfigurationId has "scid-4001"
        | where IsCompliant == "0"
        | where IsApplicable == "1"
        | extend Folder = parse_json(Context)[0][0]
        | extend Path = parse_json(Context)[0][1]
        | project DeviceId, DeviceName, OSPlatform, Folder, Path;
    let DeviceInformation = DeviceInfo
        | where ExposureLevel has "High"
        | distinct DeviceId, ExposureLevel;
    union DevVulNetShares, DeviceInformation
        | summarize by DeviceId
        | join ( DevVulNetShares ) on DeviceId
        | join kind=leftouter ( DeviceInformation ) on DeviceId
        | project DeviceId,
                DeviceName,
                OSPlatform, 
                Folder
```
