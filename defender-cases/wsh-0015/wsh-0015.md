## WSH-0015 Rclone software detection

## Document Classification

## Overview

The following query will detect execution of the Rclone command-line program which is related to ransomware exfiltration activity.

## Applicability & Technical Requirements

This use case is applicable to customers that subscribe to the Wortell MDR **Device Protect** module.

### How to Detect?

The **"DeviceProcessEvents"** we can hunt on this application what attackers using for data exfiltration.

### KQL

```kql
let Timeframe = 1d; // Choose the best timeframe for your investigation
DeviceProcessEvents
    | where Timestamp > ago(Timeframe)
    | where ProcessVersionInfoProductName has "Rclone"
    | where ProcessCommandLine contains @"rclone" or ProcessCommandLine contains @"--Launch"
    | project Timestamp, DeviceName, FolderPath, FileName, ProcessCommandLine, ProcessCreationTime, AccountName, AccountUpn
    | sort by Timestamp desc
    | project AccountUpn,DeviceName, FolderPath,ProcessCommandLine
```

## How to Investigate?

1. Confirm business justification
    * Determine whether Rclone is approved for use in your environment and whether the executing user or device has a legitimate need for cloud synchronization tools.
    * Check internal documentation or change records for sanctioned backups or migration activities.

2. Analyze the command-line intent
    * Review the command-line parameters to identify source paths, destination cloud providers, encryption flags, or bandwidth throttling—these often reveal exfiltration intent.
    * Pay close attention to headless or launch-based execution, which may indicate automation or attacker-driven use.

3. Assess account and device risk
    * Evaluate whether the executing account has elevated privileges or access to sensitive data repositories.
    * Determine if the device normally runs administrative or data-transfer tools, or if this is anomalous behavior.

4. Correlate with data access activity
    * Investigate whether large volumes of files were accessed, staged, or compressed shortly before or during Rclone execution.
    * Look for concurrent archive creation, database exports, or directory enumeration on the same system.

5. Review network and cloud impact
    * Identify outbound connections to cloud storage providers and check whether new storage accounts or tokens were configured.
    * Assess whether data was transferred outside approved geographic or organizational boundaries.
