## WSH-0010 Lumma Stealer Malware

## Document Classification

This document is only for internal use of Wortell Managed Detection and Response.

## Introduction

The purpose of this document is to explain why usecase _"WSH-0010 Lumma Stealer Malware"_ has been created, how to use it.

### Required Access

These hunting cases are linked through a published application that grants us permission to perform threat hunting via the API in our customers' security portals.

### Custom Changes

* No custom changes are made.

## Overview

A recent cybersecurity threat where hackers have created nearly 1,000 fake websites mimicking Reddit and WeTransfer. These fraudulent sites are used to distribute the Lumma Stealer malware, which is designed to steal sensitive information such as passwords and session tokens. The campaign highlights the ongoing risks posed by info-stealer malware, which can compromise both individual and organizational data. These fake websites were found by Sekoia researcher crep1x, who shared a complete list of web pages participating in the scheme.

## Applicability & Technical Requirements

This use case is applicable to customers that subscribe to the Wortell MDR **Device Protect** module.

### How to Detect?

The **"DeviceFileEvents"** we can hunt on strange activity based on file creation, Drive load event and Tampering attempt detection.

### KQL

```kql
    let FakeRedditLummaS=externaldata(RawData:string)
    [h'https://gist.githubusercontent.com/qbourgue/071c333ff5182f031da3ba55cc7da1ec/raw/ec4ba396c0d1052cc8b0a69c1bad1e0e5aef2ab6/malicious_domains_impersonating_reddit_wetransfer_selfau3_dropper_lumma_stealer_20012025.txt']
    | parse RawData with FRDdomains:string;
    let FakedRedditDomain =
    FakeRedditLummaS
    | distinct FRDdomains;
    DeviceNetworkEvents
    | where Timestamp > ago(30d)
    | where ActionType == @"HttpConnectionInspected"
    | extend Host = parse_json(AdditionalFields)["host"]
    | extend Direction = parse_json(AdditionalFields)["direction"]
    | where Direction == "Out" and Host has_any(FakedRedditDomain)
```

## How to Investigate?

1. Validate the destination and user interaction
    * Confirm whether the contacted domain is a known impersonation of Reddit or WeTransfer and not a legitimate subdomain.
    * Determine how the user reached the site (search results, ads, email link, social media, or direct navigation).

2. Assess malware delivery risk
    * Identify whether any files were downloaded around the time of the connection, especially executables, archives, or script-based droppers.
    * Check browser activity for auto-download behavior or prompt-based execution shortly after the site visit.

3. Correlate with endpoint execution
    * Review subsequent process creation events for signs of AutoIt, PowerShell, cmd, rundll32, or renamed binaries commonly used by Lumma droppers.
    * Look for persistence mechanisms such as registry run keys, scheduled tasks, or startup folder modifications.

4. Evaluate credential and data exposure
    * Lumma Stealer targets browser credentials, crypto wallets, and session tokens—verify whether the affected device accessed sensitive accounts after the visit.
    * Investigate abnormal authentication attempts, token reuse, or account access from new locations following the event.

5. Check lateral spread and reuse
    * Determine if the same fake domain was contacted by multiple devices, indicating a broader phishing or malvertising campaign.
    * Assess whether similar browser extensions or downloads appear across affected endpoints.
