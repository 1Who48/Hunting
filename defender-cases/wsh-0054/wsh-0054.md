## WWSH-0054 BiDi Swap URL in DeviceNetworkEvents

## Document Classification

This document is only for internal use of Wortell Managed Detection and Response.

## Introduction

The purpose of this document is to explain why usecase _"WSH-0054 BiDi Swap URL in DeviceNetworkEvents"_ has been created, how to use it.

### Required Access

These hunting cases are linked through a published application that grants us permission to perform threat hunting via the API in our customers' security portals.

### Custom Changes

* No custom changes are made.

## Overview

This analytic looks for percent-encoded Unicode Bi-Directional (BiDi) control characters embedded in URLs observed in DeviceNetworkEvents. Attackers abuse these invisible characters—most notably:

* U+202E Right-to-Left Override (RLO) → %E2%80%AE
* U+200E Left-to-Right Mark (LRM) → %E2%80%8E
* U+200F Right-to-Left Mark (RLM) → %E2%80%8F

To visually reorder or mask parts of a URL. When rendered, a malicious URL can appear benign (e.g., reversing path/file segments), tricking users and sometimes bypassing naïve string-matching controls. Your rule flags any network event whose RemoteUrl contains these encodings so you can triage clicks, process origins, and destinations.

## Applicability & Technical Requirements

This use case is applicable to customers that subscribe to the Wortell MDR **DeviceProcessEvents** module.

### How to Detect?

1. Match percent-encoded BiDi controls in RemoteUrl (your current query).
2. Decode once and search for raw Unicode controls (\u202E, \u200E, \u200F) because some telemetry already normalizes URLs.
3. Handle double-encoding (e.g., %25E2%2580%AE) by decoding twice.
4. Expand coverage to other common BiDi/zero-width controls attackers use:
     * LRE %E2%80%AA (U+202A), RLE %E2%80%AB (U+202B), PDF %E2%80%AC (U+202C)
     * LRO %E2%80%AD (U+202D), ZWJ %E2%80%8D (U+200D), ZWNJ %E2%80%8C (U+200C)

5. Search other data sources where links appear/clicks originate:
     * EmailUrlInfo, EmailEvents, UrlClickEvents (MDO)
     * DeviceProcessEvents (command-line, child processes curling/wgeting such URLs)
     * DeviceWebContentEvents or CloudAppEvents (if available)

### KQL

```kql
     let bidi_chars = dynamic(['%E2%80%AE', '%E2%80%8E', '%E2%80%8F']);
     DeviceNetworkEvents
     | where TimeGenerated <= ago(1d)
     | where isnotempty(RemoteUrl)
     // Suche nach den prozentkodierten BiDi-Zeichen in der URL
     | where RemoteUrl has_any (bidi_chars)
     | project Timestamp, DeviceName, DeviceId, RemoteUrl, ActionType, InitiatingProcessFileName, RemoteIP, RemotePort, ReportId
     | extend Bidi_Character_Found = extract_all(@"(%E2%80%AE|%E2%80%8E|%E2%80%8E)", RemoteUrl)
```

## How to Investigate?

1. review the suspicious URL structure  
   - examine the full RemoteUrl to understand how the BiDi characters are embedded  
   - determine if the URL visually disguises file extensions or domain names  
   - check whether the URL appears intentionally obfuscated  

2. analyze the initiating process  
   - identify which application made the network request  
   - verify whether the process normally accesses external URLs  
   - review the file path and execution context of the process  

3. assess user interaction context  
   - determine whether the activity was user-driven (browser click) or automated  
   - correlate with recent email, Teams, or web activity on the device  
   - check if the user accessed suspicious content shortly before  

4. review destination reputation  
   - check if the remote IP or domain has known malicious history  
   - identify hosting provider and geolocation  
   - look for signs of recently registered or disposable infrastructure  

5. correlate with follow-on behavior  
   - check for file downloads after the connection  
   - look for new processes spawned by browsers or script hosts  
   - review file creation in temp or download directories  

6. scope across the environment  
   - search for other devices contacting URLs with BiDi characters  
   - identify repeated patterns or shared domains  
   - determine if this is isolated or part of a wider campaign
