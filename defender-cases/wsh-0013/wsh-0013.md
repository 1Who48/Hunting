## WSH-0013 UMWorkerProcess Creating Webshell

## Document Classification

This document is only for internal use of Wortell Managed Detection and Response.

## Introduction

The purpose of this document is to explain why usecase _"WSH-0013 UMWorkerProcess Creating Webshell"_ has been created, how to use it.

### Required Access

These hunting cases are linked through a published application that grants us permission to perform threat hunting via the API in our customers' security portals.

### Custom Changes

* No custom changes are made.

## Overview

This query detects unusual file content created by UMWorkerProcess, indicating exploitation of CVE-2021-26858 to generate a web shell.

### MITRE ATT&CK

This attack tactic can be mapped on the MITRE ATT&CK framework:

| Tactic                | Techniques |
|-----------------------|------------|
| Execution             | T1059      |

## Applicability & Technical Requirements

This use case is applicable to customers that subscribe to the Wortell MDR **Device Protect** module.

### How to Detect?

The **"DeviceActivity"** based on the DeviceFileEvents we can analyze file creation by the UMWorkerProcess.

### KQL

```kql
    DeviceFileEvents
    | where TimeGenerated > ago(1d)
    | where InitiatingProcessFileName == "UMWorkerProcess.exe" 
    | where FileName !in~("CacheCleanup.bin", "cleanup.bin")
    | where FileName !endswith ".txt"
    | where FileName !endswith ".LOG" 
    | where FileName !endswith ".cfg"
```

## How to Investigate?

1. Validate process legitimacy
    * Confirm that UMWorkerProcess.exe is the genuine Microsoft binary, running from the expected installation path and signed by Microsoft.
    * Check whether the process version aligns with the installed Exchange or messaging components on the host.

2. Review the created or modified files
    * Identify the file names, extensions, and directories involved—non-text, non-log, and non-config files are unusual for this process.
    * Assess whether the files resemble executables, scripts, archives, or encoded payloads.

3. Analyze execution context
    * Determine what triggered UMWorkerProcess.exe at the time of file activity (scheduled task, service restart, external request, or chained process).
    * Look for unexpected parent or child processes that could indicate process injection or abuse.

4. Assess for exploitation or post-exploitation
    * Exchange-related worker processes are common targets for web shell deployment and privilege escalation—evaluate whether this activity aligns with known Exchange exploitation patterns.
    * Check whether the files were placed in web-accessible or startup locations.

5. Correlate with network and authentication activity
    * Review outbound connections, mailbox access, or administrative actions following the file creation.
    * Look for signs of lateral movement or credential access tied to the same host or service account.
