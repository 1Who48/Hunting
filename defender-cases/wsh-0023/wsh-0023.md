## Applicability & Technical Requirements

This use case is applicable to customers that subscribe to the Wortell MDR **Device Protect** module.

### How to Detect?

Detects activities of disabling for Microsoft Defender Antivirus and Microsoft Defender for Endpoint in the **"DeviceNetworkEvents"** table

### KQL

```kql
let WeeklyOSINT=externaldata(Type:string, Value:string, Source:string)
      [h'https://raw.githubusercontent.com/SlimKQL/Hunting-Queries-Detection-Rules/refs/heads/main/IOC/SnakeLogger.csv'];
      let OSINTSHA256 =
      WeeklyOSINT
      | where Type == "hash_sha256"
      | project Value;
      let OSINTSHA1 =
      WeeklyOSINT
      | where Type == "hash_sha1"
      | project Value;
      let OSINTMD5 =
      WeeklyOSINT
      | where Type == "hash_md5"
      | project Value;
      let OSINTDOMAIN =
      WeeklyOSINT
      | where Type == "domain"
      | project Value;
      let OSINTURL =
      WeeklyOSINT
      | where Type == "url"
      | project Value;
      let OSINTIP =
      WeeklyOSINT
      | where Type == "ip"
      | project Value;
      let ScanEmailAttachments =
      EmailAttachmentInfo
      | where Timestamp > ago(1d)
      | where SHA256 has_any(OSINTSHA256);
      let ScanEmailURLs =
      EmailUrlInfo
      | where Timestamp > ago(1d)
      | where UrlDomain has_any(OSINTDOMAIN) or Url has_any(OSINTURL);
      let ScanEndpointFiles =
      DeviceFileEvents
      | where Timestamp > ago(1d)
      | where ActionType == "FileCreated"
      | where MD5 has_any(OSINTMD5) or SHA1 has_any(OSINTSHA1) or SHA256 has_any(OSINTSHA256);
      let ScanEndpointNetwork1 =
      DeviceNetworkEvents
      | where Timestamp > ago(1d)
      | where ActionType == "ConnectionSuccess"
      | where RemoteIP has_any (OSINTIP) or RemoteUrl has_any (OSINTDOMAIN);
      let ScanEndpointNetwork2 =
      DeviceNetworkEvents
      | where Timestamp > ago(1d)
      | where ActionType == "HttpConnectionInspected"
      | extend ConnectInfo = todynamic(AdditionalFields)
      | extend HttpHost = ConnectInfo.host
      | where HttpHost has_any(OSINTDOMAIN);
      union ScanEmailAttachments, ScanEmailURLs, ScanEndpointFiles, ScanEndpointNetwork1, ScanEndpointNetwork2
```

## How to Investigate?

1. Triage what matched and where it matched
      * Separate results by source (email attachments, email URLs, file creation, network connections) and note which indicator type triggered it (hash, domain, URL, IP).
      * Prioritize matches on file hashes and confirmed outbound connections.

2. Validate the indicator context
      * Check whether the matched hash/domain/IP is a true positive for SnakeLogger activity or could be shared/benign (e.g., common hosting, URL shorteners, CDNs).
      * Use the “Source” field from the OSINT feed to understand confidence and recency.

3. Investigate email-based entry (if attachment/URL hits)
      * Identify the recipient(s), sender(s), subject, and delivery path. Determine who clicked the URL or opened/saved the attachment, and whether the message was delivered to additional users (similar recipients, same campaign, same sender domain).

4. Investigate endpoint execution chain (if file creation hits)
      * On affected devices, review what created the file (parent process, command line, script engine, Office child process, archive extraction, user context).
      * Confirm whether the file was executed and look for follow-on behaviors typical of infostealers (credential access, browser data access, persistence attempts).

5. Investigate network behavior (if IP/domain/host hits)
      * Determine which devices/accounts connected, how often, and whether connections cluster around user activity or run headless/automated.
      * Look for associated DNS lookups, TLS SNI/host patterns, repeated beaconing, and any data transfer spikes that could suggest exfiltration.
