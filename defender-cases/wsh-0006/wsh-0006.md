## WSH-0006 New Information Stealer - SamsStealer (By CYFIRMA)

## Document Classification

This document is only for internal use of Wortell Managed Detection and Response.

## Introduction

The purpose of this document is to explain why usecase _"WSH-0006 New Information Stealer - SamsStealer (By CYFIRMA)"_ has been created, how to use it.

### Required Access

These hunting cases are linked through a published application that grants us permission to perform threat hunting via the API in our customers' security portals.

## Overview

SamsStealer, represents a new wave of information stealers targeting Windows systems. This malicious executable, written in.NET, has been observed propagating in a Telegram channel named “SamsExploit”

### MITRE ATT&CK

This attack tactic can be mapped on the MITRE ATT&CK framework:

|-----------------------|------------|
|  Command and Control  | T1071      |

## Applicability & Technical Requirements

This use case is applicable to customers that subscribe to the Wortell MDR **Device Protect** module.

### How to Detect?

The **"DeviceFileEvents"** we can hunt on ICO to detected if this software is active on the endpoints.

### KQL

```kql
    let WebTelegramPC =
    DeviceNetworkEvents 
    | where ActionType == @"HttpConnectionInspected"
    | extend ConnectInfo = todynamic(AdditionalFields)
    | extend HttpHost = ConnectInfo.host
    | where HttpHost contains "web.telegram.org"
    | distinct DeviceName;
    DeviceEvents
    | where Timestamp > ago(1d)
    | where DeviceName has_any(WebTelegramPC)
    | where MD5 == "83f94302ae92909bc3b2834a5342d4a5" or MD5 == "824e149b9c2bdd5dbe37f472533230af" or MD5 == "1f913f8d71f0f4d65858b5ba0ea94a9c" or MD5 == "56acc1496d8e5bbc0e412c683971b809" or MD5 == "631eacb4519fd49048491c9b5ec6bda5" or MD5 == "64410e06f80e75b6503e5525c323243b" or MD5 == "7d63047a48fa8984f11544149c2f0e70" or MD5 == "da493648ca3b8fd9dbad7bbca659b796" or MD5 == "02fe599ed41cc4bd54a1d6a3cc2d830a" or MD5 == "cb95c77750732c0a4dd29c1d4feb6f69" or MD5 == "11751f8d847764936b7bf014302da87f" or MD5 == "31c73ad35b23e4d98ed974e604b85e00"
```

## How to Investigate?

1. Understand the Scope
    * Identify devices that connected to web.telegram.org in the network.
    * Determine whether this access is expected or allowed within the organization.
    * Validate the list of devices that match this behavior.

2. Validate the Hashes Detected
    * Confirm whether the MD5 hashes listed correspond to known malware, suspicious executables, or legitimate software.
    * Check internal threat intelligence or vendor feeds for classification of these hashes.
    * Determine if these files should exist anywhere in the environment.

3. Review Device Activity
    * Check each affected device for additional indicators of compromise.
    * Identify how many devices have executed or interacted with files matching the suspicious hashes.
    * Determine if the activity occurred only once or repeatedly.

4. Assess User Behavior
    * Identify which users were logged into the affected devices when the activity occurred.
    * Determine whether these users are known to use Telegram for work or private communication.
    * Assess whether these users have shown any previous risky behavior or compromised credentials.

5. Analyze Network Activity
    * Review whether the devices have any additional communication with Telegram domains outside normal browsing.
    * Determine if any unusual outbound connections occurred around the same timeframe.
    * Look for signs of data exfiltration or command-and-control behavior.

6. Examine File Execution Context
    * Identify what process executed or created the files corresponding to the flagged MD5 hashes.
    * Determine if the files were downloaded, side-loaded, or executed by another suspicious process.
    * Check whether these files persist on the device or were temporary artifacts.
