## WSH-0021 Hunting Malicious Chrome Extension

## Document Classification

This document is only for internal use of Wortell Managed Detection and Response.

## Introduction

The purpose of this document is to explain why usecase _"WSH-0021 Hunting Malicious Chrome Extension"_ has been created, how to use it.

### Required Access

These hunting cases are linked through a published application that grants us permission to perform threat hunting via the API in our customers' security portals.

### Custom Changes

* No custom changes are made.

## Overview

A new attack campaign has targeted known Chrome browser extensions, leading to at least 16 extensions being compromised and exposing over 600,000 users to data exposure and credential theft.

### MITRE ATT&CK

This attack tactic can be mapped on the MITRE ATT&CK framework:

| Tactic                | Techniques |
|-----------------------|------------|
| Exfiltration          | T1567      |

## Applicability & Technical Requirements

This use case is applicable to customers that subscribe to the Wortell MDR **Device Protect** module.

### How to Detect?

The **"DeviceActivity"** based on the  DeviceProcessEvents  we can hunt on strange activity based on the MSBuild as LOLBin attack.

## How to Investigate?

Please check if the plugin extension id in the following [CyberHaven ExtensionID List](https://www.extensiontotal.com/cyberhaven-incident-live). You can also see if the extensionid has been updated. Cross refference that update with the version displayed next to the extensionid in your entitity list to either mark it as "No threat". Or notify the customer about a vulnerable Chrome Extension.

You can use the following template

```text

We just investigated a “WSH-0049 Hunting Malicious Chrome Extension” incident and would like to verify the following actions that were witnessed within your environment.

Investigation description:

During our daily hunts we found a malicious/compromised Chrome extension. Please check the following entities.

Extension: 
Device: 

We strongly advise to wipe the device and put a policy in place to block extensions from being installed freely by users.

Recent security breaches have compromised several well-known Chrome extensions, with at least 36 extensions reported as affected.

The incident was detected by Cyberhaven and more information can be read here: [When Chrome Extensions Turn Against Us: The Cyberhaven Breach and Beyond | by Amit Assaraf | ExtensionTotal | Dec, 2024 | Medium](https://medium.com/extensiontotal/when-chrome-extensions-turn-against-us-the-cyberhaven-breach-and-beyond-9e35e59e1bff)
The list of malicious extensions can be found here: [Cyberhaven Incident](https://www.extensiontotal.com/cyberhaven-incident-live)

Investigation conclusion:

At this time we are unable to verify if the actions mentioned above are legitimate behavior device.

Can you please check the device and get back to us?

If you have any questions regarding the above, please do not hesitate to contact us.
```
