## WSH-0019 Detecting the use of the EDRSilencer tool

## Document Classification

## Introduction

## Overview

This KQL query searches Microsoft Defender telemetry for activity related to a specific executable named EDRSilencer.exe within the last 24 hours.

## Applicability & Technical Requirements

This use case is applicable to customers that subscribe to the Wortell MDR **Device Protect** module.

### How to Detect?

Overall, the query is designed to quickly identify any process executions or file operations involving EDRSilencer.exe, which can help detect potential security evasion tools attempting to interfere with endpoint protection.

### KQL

```kql
  let _FileName = "EDRSilencer.exe";
  let _Timestamp = 1d;
  union isfuzzy=true DeviceProcessEvents, DeviceFileEvents
  | where Timestamp > ago(_Timestamp)
  | where FileName has _FileName
```

## How to Investigate?

1. Validate process context
   - Review parent process and command-line arguments
   - Identify user account and privilege level used to launch it
   - Check execution path for anomalies

2. Establish timeline
   - Correlate with other events around the same timestamp
   - Identify first seen vs repeated executions
   - Look for preceding file download or extraction activity

3. Analyze file origin
   - Determine how the file was introduced to the system
   - Check for email, browser, or removable media involvement
   - Review file creation and modification history

4. Assess host behavior
   - Look for unusual child processes
   - Identify registry or scheduled task creation
   - Check for service modifications or stops

5. Network activity review
   - Inspect outbound connections after execution
   - Identify suspicious domains or IP addresses
   - Determine protocol and port usage patterns

6. Scope impact
   - Search for the same file across other endpoints
   - Identify common user accounts or devices involved
   - Look for lateral movement indicators
