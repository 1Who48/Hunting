## WSH-0408 Detection on suspicious application from other country

## Document Classification

This document is only for internal use of Wortell Managed Detection and Response.

## Introduction

The purpose of this document is to explain why usecase _"WSH-0408 Detection on suspicious application from other country"_ has been created, how to use it.

### Required MDR Modules and Sentinel Connectors

| MDR Module                 | Required Data Connectors          |
| -------------------------- | ----------------------------------|
| **Identity Protect Cloud** | Microsoft Defender for Identity   |

### Custom Changes

* Exclusions made for suspiciousApps = dynamic(["Azure Portal","Microsoft Azure CLI","Azure Active Directory PowerShell","OfficeHome"]);

## Overview

This hunting case helps identify suspicious application from other country by username and sign-in.

### MITRE ATT&CK

This attack tactic can be mapped on the MITRE ATT&CK framework:

| Tactic                | Techniques |
|-----------------------|------------|
| Credential Access     | T1606      |
| Lateral Movement      | T1550      |

## Applicability & Technical Requirements

This use case is applicable to customers that subscribe to the Wortell MDR **Identity Protect Cloud** module.

### How to Detect?

The **"Identity Protect Cloud"** logs of the customer need to be exported to the Wortell MDR Sentinel Log Analytics Workspace with the Microsoft Sentinel **"Microsoft Defender for Identity"** connector of Sentinel.

### KQL

```kql
    let suspiciousApps = dynamic(["Azure Portal","Microsoft Azure CLI","Azure Active Directory PowerShell","OfficeHome"]);
    let userApps = SigninLogs
    | where TimeGenerated between (ago(180d) .. ago(1d))
    //| where UserPrincipalName == UPN
    | summarize usedapps = make_set(AppDisplayName) by UserPrincipalName;
    SigninLogs
    | where TimeGenerated > ago(1d)
    //| where UserPrincipalName == UPN
    | summarize apps = make_set(AppDisplayName) by UserPrincipalName
    | join kind=leftouter userApps on UserPrincipalName
    | where isnotempty(apps) and isnotempty(usedapps)
    | extend appCounts = array_length(set_intersect(apps, usedapps))
    | where appCounts > 3 and array_length(set_difference(apps, usedapps, suspiciousApps)) > 0
    | project UserPrincipalName, SuspiciousApps = set_difference(apps, usedapps, suspiciousApps)
    | join kind=leftouter (
        SigninLogs
        | where TimeGenerated between (ago(180d) .. ago(1d))
        //| where UserPrincipalName == UPN
        | summarize usedCountries = make_set(LocationDetails[0].countryOrRegion) by UserPrincipalName
    ) on UserPrincipalName
    | extend suspiciousCountries = set_difference(usedCountries, dynamic(  ["null"]))
    | where array_length(suspiciousCountries) > 0
```
