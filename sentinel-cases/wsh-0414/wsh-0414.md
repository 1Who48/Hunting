## WSH-0414 User made Owner of multiple teams

## Document Classification

This document is only for internal use of Wortell Managed Detection and Response.

## Introduction

The purpose of this document is to explain why usecase _" WSH-0414 User made Owner of multiple teams"_ has been created, how to use it.

### Required MDR Modules and Sentinel Connectors

| MDR Module                 | Required Data Connectors |
| -------------------------- | ------------------------ |
| **Office Protect**         | Microsoft 365 Defender   |

### Custom Changes

* No customer changes are made for this hunt case.

## Overview

This hunting query identifies users who have been made Owner of multiple Teams.

### MITRE ATT&CK

This attack tactic can be mapped on the MITRE ATT&CK framework:

| Tactic                | Techniques |
|-----------------------|------------|
| Privilege Escalation  | T1078      |

## Applicability & Technical Requirements

This use case is applicable to customers that subscribe to the Wortell MDR **Office Protect** module.

### How to Detect?

The **"OfficeActivity"** logs of the customer need to be exported to the Wortell MDR Sentinel Log Analytics Workspace with the Microsoft Sentinel **"Microsoft Defender for Office 365"** connector of Sentinel.

### KQL

```kql
    let max_owner_count = 5;
    let high_owner_count = (OfficeActivity
    | where OfficeWorkload =~ "MicrosoftTeams"
    | where Operation =~ "MemberRoleChanged"
    | where TimeGenerated > ago(1d)
    | extend Member = tostring(parse_json(Members)[0].UPN) 
    | extend NewRole = toint(parse_json(Members)[0].Role) 
    | where NewRole == 2
    | summarize dcount(TeamName) by Member
    | where dcount_TeamName > max_owner_count
    | project Member);
    OfficeActivity
    | where OfficeWorkload =~ "MicrosoftTeams"
    | where Operation =~ "MemberRoleChanged"
    | extend Member = tostring(parse_json(Members)[0].UPN) 
    | extend NewRole = toint(parse_json(Members)[0].Role) 
    | where NewRole == 2
    | where Member in (high_owner_count)
    | extend timestamp = TimeGenerated, AccountCustomEntity = Member
    | project UserId, RecordType,Operation,TeamName,ItemName
```

## How to Investigate?

To investigate this use case, detect who added the user to multiple teams, also check the names of the teams channels to identify sensitive data where the user could have access to.
