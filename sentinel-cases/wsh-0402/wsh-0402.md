## WSH-0402 New executable via Office FileUploaded

## Overview

This use case identifies when executable file types are uploaded to Office services such as SharePoint and OneDrive when its not owned by the user it self. State their own sharepoint location or onedrive.

### How to Detect?

The first part of the query retrieves Office file activity from the last day (endtime = 1d), scoped to SharePoint and OneDrive workloads, specifically `FileUploaded` operations where the file carries an executable extension.

Uploads from known service accounts (e.g. `app@sharepoint`, used for automated backups, retention and migration jobs) are excluded up front to reduce noise. Extension matching is done as an exact, case-insensitive match against the `execExt` list rather than a term match.

The query then checks against activity from the last 8 days (starttime = 8d) to see if the same file (by name, path and user) has been observed before. Combinations seen more than the `threshold` (default 2) are treated as known and excluded.

It then checks whether the uploaded file is located in a SharePoint/OneDrive personal folder that corresponds to the uploading user's own ID; self-uploads to a user's own personal folder are filtered out.

Finally, results are aggregated per user / IP / site so that a single user uploading multiple new executables produces one alert (with an `UploadCount`) rather than one alert per file.

### KQL

```kql
    let threshold = 2;
    let uploadOp = 'FileUploaded';
    let execExt = dynamic(['exe', 'cmd', 'bat', 'ps1', 'vbs', 'scr', 'msi']);
    let excludedUsers = dynamic(['app@sharepoint']);
    let starttime = 8d;
    let endtime = 1d;
    OfficeActivity
    | where TimeGenerated >= ago(endtime)
    | where OfficeWorkload in ("SharePoint", "OneDrive")
    | where Operation =~ uploadOp
    | where UserId !in~ (excludedUsers)
    | where SourceFileExtension in~ (execExt)
    | project TimeGenerated, OfficeId, OfficeWorkload, RecordType, Operation, UserType,
              UserKey, UserId, ClientIP, UserAgent, Site_Url, SourceRelativeUrl, SourceFileName
    | join kind=leftanti (
        OfficeActivity
        | where TimeGenerated between (ago(starttime) .. ago(endtime))
        | where OfficeWorkload in ("SharePoint", "OneDrive")
        | where Operation =~ uploadOp
        | where UserId !in~ (excludedUsers)
        | where SourceFileExtension in~ (execExt)
        | summarize SourceRelativeUrl = make_set(SourceRelativeUrl),
                    UserId = make_set(UserId),
                    PrevSeenCount = count()
            by SourceFileName
        | where PrevSeenCount > threshold
        | mv-expand SourceRelativeUrl, UserId
        | extend SourceRelativeUrl = tostring(SourceRelativeUrl), UserId = tostring(UserId)
    ) on SourceFileName, SourceRelativeUrl, UserId
    | extend SiteUrlUserFolder = tolower(split(Site_Url, '/')[-2])
    | extend UserIdUserFolderFormat = tolower(replace("[@.]", "_", UserId))
    | extend UserIdIsUserFolder = iff(Site_Url has '/personal/' and SiteUrlUserFolder == UserIdUserFolderFormat, true, false)
    | where UserIdIsUserFolder == false
    | summarize TimeGenerated = make_list(TimeGenerated), StartTime = min(TimeGenerated), EndTime = max(TimeGenerated),
                UserAgents = make_set(UserAgent), OfficeIds = make_list(OfficeId),
                SourceRelativeUrls = make_set(SourceRelativeUrl), FileNames = make_set(SourceFileName),
                UploadCount = count()
        by OfficeWorkload, RecordType, Operation, UserType, UserKey, UserId, ClientIP, Site_Url
    | extend timestamp = StartTime, AccountCustomEntity = UserId, IPCustomEntity = ClientIP, URLCustomEntity = Site_Url
```

## How to Investigate?

To investigate this use case, investigate the files that are uploaded to the location. Define the context in which the file was placed.

* Who placed the file?
* Where was the file placed?
* What is the file?

**User Authentication Context**  
Check if the user logged in from an Azure AD Joined Device or a known location
Investigate unfamiliar devices or unusual locations.

**File Context Analysis**  
Verify if the uploaded **EXE files align with the user’s department** and the expected **SharePoint folder structure**.
Check if similar file uploads have occurred in the past.  
Identify deviations from normal user behavior.

**File Reputation Analysis**  
Submit the **file hash** to **VirusTotal**.  

**IP Address Analysis**
Investigate unknown or unusual IP addresses.
Verify if the **ClientIP** matches historical patterns or known locations.
