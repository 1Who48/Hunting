## WSH-0434 Azure Role assignments to newly added guest user accounts

## Document Classification

This document is only for internal use of Wortell Managed Detection and Response.

## Introduction

The purpose of this document is to explain why usecase _"WSH-0434 Azure Role assignments to newly added guest user accounts"_ has been created and how to use it.

### Required Access

The hunting cases are executed via a published Azure Active Directory application in the customer tenant that enables the MDR hunting team to hunt via the Advanced Hunting API.

### Custom Changes

* No customer changes are made for this hunt case.

## Overview

This usecase detects Azure Role assignments to newly added guest user accounts.

## Applicability & Technical Requirements

This use case is applicable to customers that subscribe to the Wortell MDR **Identity Protect Cloud** module.

### How to Detect?

The **"AuditLogs"** table can be used to hunt for action on user/guest accounts. Related activities will be detected with the following KQL query:

### KQL

```kql
    let newGuestAccounts = AuditLogs
    | where TimeGenerated > ago(1d) 
    | where OperationName == "Add user" 
    | mv-expand TargetResources = TargetResources 
    | mv-expand  ModifiedProperties = TargetResources.modifiedProperties  
    | where ModifiedProperties.displayName == "UserType" and ModifiedProperties.newValue has "Guest" 
    | summarize by tostring(TargetResources.id); 
    AzureActivity 
    | where OperationNameValue == "MICROSOFT.AUTHORIZATION/ROLEASSIGNMENTS/WRITE"  
    | extend Properties=parse_json(Properties) 
    | extend requestbody = parse_json(tostring(parse_json(Properties).requestbody)) 
    | extend PrincipalId= requestbody.Properties.PrincipalId 
    | extend RoleDefinitionId= requestbody.Properties.RoleDefinitionId 
    | extend Scope= requestbody.Properties.Scope 
    | extend Entity = tostring(Properties.entity) 
    | where PrincipalId in (newGuestAccounts)  
    | join kind=inner ( 
    AzureActivity 
    | where OperationNameValue == "MICROSOFT.AUTHORIZATION/ROLEASSIGNMENTS/WRITE" 
    | where ActivityStatusValue != "Start" | extend Entity = tostring(parse_json(Properties).entity) ) on CorrelationId,Entity,OperationNameValue 
    | project TimeGenerated,OperationNameValue,PrincipalId,RoleDefinitionId,FinalStatus = ActivityStatusValue1, Caller, Properties
```

To investigate this use case, check the guest account and to what roll the account was added. if needed please inform the customer related to the guest user have access to azure roles.
