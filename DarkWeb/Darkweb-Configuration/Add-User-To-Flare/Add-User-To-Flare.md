## Adding a User to Flare.io

## Overview

This document provides step-by-step instructions on how to add a new user to Flare.io. This process ensures that the new user has the appropriate permissions and access to the platform.

## Prerequisites

Before adding a user, ensure the following:

* You have administrative privileges on Flare.io.
* You have the new user’s email address.
* The user has been informed about Flare.io and is prepared to receive the invitation email.

## Steps to Add a User

Step 1: Log into Flare.io

1. Open your web browser and navigate to Flare.io.
2. Enter your credentials and log in to the admin dashboard.

Step 2: Access User Management

1. From the dashboard, locate the Admin Panel or Settings menu.
2. Click on User Management or Users.

Step 3: Add a New User

1. Click the Add User or Invite User button.
2. Enter the required details:
    * Email Address: Input the user’s email.
    * Role: Select the appropriate role (e.g., Admin, Editor, Viewer). We Always use Viewer
    * Permissions: Configure necessary permissions if applicable.
3. Click Send Invitation or Add User.

Step 4: User Acceptance

1. The new user will receive an email invitation.
2. They need to click the invitation link and set up their account.
3. Once completed, they will have access to Flare.io based on the assigned role.

## Managing Users

* To edit user roles or permissions, go to User Management and select the user to update their details.
* To remove a user, navigate to User Management, select the user, and click Remove or Deactivate.

## Troubleshooting

* If the user does not receive the invitation email, ask them to check their spam folder.
* Ensure the entered email address is correct.
* If issues persist, contact Flare.io support.

Conclusion

Adding a user to Flare.io is a simple process that involves sending an invitation and assigning the right permissions. Regularly review user access to maintain security and efficiency.

More information with screens can be found on: [https://docs.flare.io/team](https://docs.flare.io/team)
