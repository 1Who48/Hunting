## Credentials-Browser

## Overview

The **Credentials Browser** in Flare is a powerful tool designed to help security teams search, track, and manage leaked credentials. It provides an intuitive interface for identifying compromised credentials across various sources, enabling proactive protection of accounts and digital assets.

## Key Features

1. **Efficient Search**: Navigate through Flare's comprehensive database of leaked credentials effortlessly.
2. **Precision Filtering**: Refine searches based on domain, reverse domain, email, username, and password for targeted investigations.
3. **Easy Tagging**: Mark results as remediated or ignored for streamlined management.
4. **Export Capability**: Export discovered credentials for reporting or integration with other security systems.

## How It Works

### Accessing the Credentials Browser

- Visit the Credentials Browser page on Flare.
- Use the search bar to look up potential matches in Flare's Leaked Credentials Database.

### Filtering Options

- Search for matching leaks by domain, email, password, and more.
- Use advanced filtering options to refine your search results.

### Tenant Feed View

- Provides a centralized view of all leaked credentials that matched your identifiers.
- Aggregates all leaked credentials for your tenant or individual identifier feeds.

### Global Search View

- Allows searching for public leaked credentials within Flare's extensive Leaks Database.
- Supports filtering by password complexity, source, and other key attributes.

## Key Differences Between Tenant Feed and Global Search Views

- **Tenant Feed View**: Limited to your tenant, used for tenant-specific monitoring.
- **Global Search View**: Broader perspective, searches across all available credentials in Flare’s database.

For more details, visit the official documentation: [Flare.io Credentials Browser](https://docs.flare.io/credentials-browser).
