## Emerging Sources Documentation

### Overview

Flare's Emerging Sources are datasets from new sources not yet fully integrated into the Flare application. These sources help address visibility gaps and enhance data coverage. Emerging Source events are raw and include basic metadata, raw content views, and no severity scoring or AI assistance.

### Key Features

- **App Stores**: Monitors app stores for unverified or malicious apps, providing visibility into illegitimate versions of mobile apps.
- **Botnet**: Intelligence on botnets, including IP addresses and target/victim company names.
- **SEC 8-K Filings**: Alerts on significant cybersecurity incidents reported by publicly traded companies.
- **PII & Unverified Leaks**: Includes various PII breaches and unverified breaches found online.
- **Ransomware Files**: Contains files related to ransomware attacks.
- **Other Found Files**: Files identified by Flare that hold potential value but don't fit into other categories.
- **Potential Stealer Logs**: Contains rejected stealer logs missing critical information or of unsupported layout.
- **DockerHub Monitoring**: Monitors public DockerHub repositories for exposed secrets and misconfigurations.

### Important Notes

- Emerging Source data may not be archived long-term.
- Flare reserves the right to add or remove emerging sources at any time.
- Feedback on emerging sources can help prioritize improvements.

For more details, visit the official documentation: [Flare.io Emerging-Sources](https://docs.flare.io/emerging-sources).
